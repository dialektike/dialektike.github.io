엔서블에서 `apt` 이용할 때 나오는 오류 처리법

2021-03-18

apt을 이용해 업그레이드할 때 통상적으로 다음과 같이 하는 경우가 많습니다.

1tasks:
2- name: Update and upgrade apt packages
3become: true
4apt:
5upgrade: yes
6update_cache: yes
7cache_valid_time: 86400 #One day

이런 경우 다음과 같은 경고가 뜰 수 있죠.

1TASK [Update and upgrade apt packages] ************************************************************************************************************************
2[WARNING]: The value "True" (type bool) was converted to "'True'" (type string). If this does not look like what you expect, quote the entire value to ensure
3it does not change.

이건 upgrade: yes을 upgrade: "yes"과 같이 바꾸면 해결됩니다. 즉 아래와 같이 하면 됩니다.

1tasks:
2- name: Update and upgrade apt packages
3become: true
4apt:
5upgrade: "yes" # not: yes
6update_cache: yes
7cache_valid_time: 86400 #One day

참고: ubuntu - Ansible warning about boolean type conversion - Stack Overflow
