맥에서 sshpass 설치하기

2021-03-09

homebrew로 sshpass이 설치되지 않는다! 아래 링크를 보면, 초보자들이 가볍게 설치하지 못 하도록 하려고 설치를 막았다고 하는 것 같다. 그래서 아래 링크에 있는 소스를 이용하는 방법으로 설치해보자! 설치한 후 다운받은 폴더와 파일을 삭제하면 된다.

1cd ~
2curl -O -L https://fossies.org/linux/privat/sshpass-1.09.tar.gz && tar xvzf sshpass-1.09.tar.gz
3cd sshpass-1.09
4./configure
5sudo make install
6sshpass
