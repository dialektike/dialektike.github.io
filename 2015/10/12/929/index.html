String 를 NSData 로, NSData 를 String 로

2015-10-12

swift에서 String를 NSData로, NSData를 String로 바꾸는 코드입니다.

1var swift_string = "lorem ipsum dolor sit amet"
2// from String to NSData
3let data = swift_string.dataUsingEncoding(NSUTF8StringEncoding)
4print(data)
5// from NSData to String
6var out: String = String(data:data!, encoding:NSUTF8StringEncoding)!
7print(out) 
8// print "lorem ipsum dolor sit amet"
